---
name: shared-pr-review
description: Revisa cambios de código antes de un pull request. Úsala para detectar errores, riesgos, pruebas faltantes, y cambios fuera de alcance.
---
1. Lee el cambio solicitado y el diff.
2. Identifica errores, regresiones y pruebas faltantes.
3. No modifiques archivos salvo que el usuario lo solicite explicitamente.
4. Entrega hallazgos ordenados por severidad.
